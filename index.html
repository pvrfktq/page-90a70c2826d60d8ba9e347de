操作说明

机场订阅的核心是「套餐 → 订阅地址 → 客户端导入 → 选节点连接」。按下面顺序做，一般不必反复试错。

  1. 在套餐区确认流量与设备额度后完成订阅，进入账户复制订阅链接，避免截图外传。
  2. 打开与系统匹配的客户端。尚未安装时，先到本页客户端分区获取对应版本。
  3. 在客户端中选择从 URL / 订阅导入，粘贴链接并更新一次节点列表。
  4. 开启系统代理或 TUN 模式（以客户端名称为准），挑选延迟较低的节点再访问目标站点。
  5. 若页面无法打开，先切换节点，再检查是否漏开代理、是否被本地防火墙拦截，或订阅是否已到期。

导入后的日常习惯

建议把订阅更新频率保持在客户端默认或每天一次，避免节点变更后仍使用过期列表。不用时关闭代理，减少对局域网打印、网盘同步的干扰。流量与到期时间以账户显示为准，临近用尽时再考虑升级，不必提前囤积。

常见问题

这一部分是本页的重点。开通前把下列问答过一遍，通常能避免把套餐买错、把链接贴错，或把系统代理模式设错。

大哥云是什么？和普通 VPN 有何不同？

大哥云是以机场订阅提供网络加速的服务说明品牌：你购买的是可导入客户端的订阅，而不是安装一个捆绑了全部节点的单一 App。和传统「一个软件里点一下连接」的 VPN 相比，机场把线路列表放在订阅里，客户端负责更新、选点和代理模式。这样你可以按设备更换客户端，也能按流量选择套餐，而不必绑定某一款界面。

第一次使用，最短要完成哪些步骤？

三件事就够：选定套餐并拿到订阅地址；安装与系统匹配的客户端；在客户端里用 URL 导入并更新节点。完成后选一条节点，打开代理再访问目标网站。若导入失败，优先检查链接是否完整复制、客户端是否支持该订阅格式，而不是反复重装系统。

客户端下载之后，订阅应该填在哪里？

大多数客户端都有「订阅」「Profiles」或「从 URL 导入」入口。把账户里的订阅整段粘贴进去，执行一次更新，节点会出现在列表中。不要把订阅链接发到群聊或公开笔记。如果客户端提示格式错误，确认没有多余空格或换行，再换官方渠道下载的版本重试。

手机和电脑可以一起用吗？设备数量怎么算？

可以在多台设备上导入同一订阅，同时在线数量以你购买的套餐说明为准。建议给每台设备单独更新一次订阅，而不是互相拷贝已经过期的配置文件。若超出同时在线限制，后接入的设备可能无法连接，此时关掉闲置终端或调整套餐即可。

已经连接，但网页打不开或时快时慢，怎么排查？

先换一条节点，排除单条线路波动。接着确认客户端处于全局、规则或直连中的哪一种模式：需要加速的站点应走代理，局域网和国内常用服务可走直连。仍异常时，检查系统时间是否准确、本地防火墙是否拦截核心进程、订阅是否到期。不要同时开多个代理工具，以免端口和规则互相覆盖。

流量、有效期和到期后的状态如何理解？

流量按套餐周期计算，用尽后需要等待重置或变更套餐，具体规则以账户与套餐模块为准。有效期结束通常意味着订阅停止更新、节点无法继续使用。建议在到期前决定是否续费，避免工作日中途中断。正文不重复罗列价格数字，下单前请直接对照套餐区展示。

订阅链接泄露了怎么办？需要重新购买吗？

若链接出现在截图、网盘或聊天记录里，应立刻在账户中重置订阅。重置后旧链接失效，已导入的设备需要重新粘贴新地址并更新。一般不必因此重新购买套餐，但要检查是否有陌生设备仍占用在线名额。平时只在本机客户端保存链接，不要写入浏览器书签的公开同步列表。
